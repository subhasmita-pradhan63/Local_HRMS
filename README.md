# Inovaantage Employee Payroll Portal

A complete employee payroll portal built with plain **HTML5 / CSS3 / JavaScript**
on the frontend, a **Node.js** backend (no Express, no framework — just the
built-in `http` module plus a handful of focused libraries), and **Oracle
Database 19c/21c** for storage.

## 2. Prerequisites

- Node.js 18 or later
- Access to an Oracle Database 19c or 21c instance (the schema uses
  `GENERATED BY DEFAULT AS IDENTITY` columns, supported from Oracle 12c+)
- Oracle connection details — from your screenshot:
  - Host: `localhost`, Port: `1521`, Service name: `orcl`
  - User: `C##INOVAANTAGE` (a common user, hence the `C##` prefix — this is
    normal for a pluggable database user)

The `oracledb` Node package used here runs in **Thin mode by default**, so
you do **not** need to install Oracle Instant Client separately for a normal
TCP connection. If your DBA requires TLS/wallet-based auth, see the
`oracledb` docs for Thick mode.

## 3. Setup steps

### Step 1 — Install dependencies
```bash
cd payroll-portal
npm install
```

### Step 2 — Configure your database connection
```bash
cp .env.example .env
```
Edit `.env` and set at minimum:
```
DB_USER=C##INOVAANTAGE
DB_PASSWORD=your_real_password
DB_HOST=localhost
DB_PORT=1521
DB_SERVICE_NAME=orcl
```
Also set `SESSION_SECRET` to any long random string.

### Step 3 — Create the database schema
Run the SQL scripts against your Oracle DB, in order, using SQL Developer,
SQL*Plus, or `sqlplus`:
```sql
@sql/01_schema.sql
@sql/02_seed_data.sql
```
(You can run them from SQL Developer's Worksheet against your `inov`
connection exactly as shown in your screenshot — connect, open each `.sql`
file, and run as script / F5.)

This creates `employees`, `app_users`, `payroll`, `upload_batches`, and
inserts:
- A default login: **username `admin`, password `Admin@123`** — change this
  after first login (there's no "change password" UI yet; update
  `app_users.password_hash` directly with a new bcrypt hash, or ask me to
  add a change-password screen).
- Three sample employees, including `INV-011 / Ananya Patnaik`, matching
  your sample payslip.
- One sample payroll record for July 2026 that reproduces your sample
  payslip exactly (Net Salary Rs.51,510 / "Fifty One Thousand Five Hundred
  Ten Only").

### Step 4 — Start the server
```bash
npm start
```
Then open **http://localhost:3000** in your browser and log in with
`admin` / `Admin@123`.

## 4. How each feature works

### Login
`POST /api/login` checks `app_users` (bcrypt password hash) and issues an
HttpOnly session cookie. All `/api/*` routes except `/api/login` require
this cookie. Sessions are held in memory and expire after
`SESSION_TTL_MINUTES` (default 120) minutes of inactivity.

### Employee Management (`employees.html`)
Full CRUD against the `employees` table, plus live search-as-you-type by
code/name and filters by department/status. Deleting an employee that still
has payroll records is blocked (foreign key) with a clear error message —
remove their payroll rows first if you really need to delete them.

### Upload Salary Excel (`upload-salary.html`)
1. Choose the pay month/year.
2. Choose (or drag-and-drop) an `.xlsx`/`.xls` file. The **first row must be
   a header row**, and it must include an **Employee Code** column (accepted
   header names: "Employee Code", "Emp Code", "Employee ID", "Emp ID",
   "Code" — case/spacing insensitive).
3. Other recognized columns (all optional, case-insensitive):
   - Attendance: Working Days, Present, Absent, Paid Leave, LOP Days,
     Half Days, Late Marks, OT Hours
   - Earnings: Basic Salary, HRA, DA, Conveyance, Medical Allowance,
     Special Allowance, Bonus, Other Earnings, Total Earnings
   - Deductions: PF, Professional Tax, Income Tax, Other Deductions,
     Total Deductions
   - Net Salary
   - If Total Earnings / Total Deductions / Net Salary are left out, the
     server calculates them from the individual fields.
4. Each row is matched to an employee by Employee Code. Matched rows are
   saved (upserted — re-uploading the same employee+period overwrites the
   old record). Unmatched employee codes are reported back to you, not
   silently dropped.
5. Every upload is logged in `upload_batches` for audit purposes.

### Payslip generation (`payroll-history.html` → Download)
`GET /api/payroll/:id/payslip` streams a PDF built with `pdfkit`, laid out
to match the sample template you provided: company header, employee
details, attendance summary tiles, earnings/deductions tables, and a net
salary banner with the amount spelled out in words (Indian numbering —
Lakh/Crore). All figures come directly from the row saved from your Excel
upload — nothing is re-derived or estimated at download time.

### Payroll History
Search by Employee Code, Name, or Department, and filter by month/year.
Each row links straight to its payslip PDF.

### Dashboard
Employee counts, total payroll records, latest period's total payout, and
a department breakdown — all pulled live from Oracle.

## 5. Notes, limitations & suggested next steps

- **Sessions are in-memory** — fine for a single Node process; if you ever
  run this behind a load balancer with multiple instances, move sessions
  into a DB table or Redis.
- **No "forgot password" or "change password" screen yet** — the seed data
  gives you one admin login to get started. Ask if you'd like a proper user
  management screen (add more HR/Admin logins, role-based permissions).
- **Role field exists** (`ADMIN` / `HR` / `VIEWER` in `app_users.role`) but
  the UI doesn't yet restrict pages by role — everyone who logs in currently
  sees everything. Happy to wire that in if you want tiered access.
- **File uploads** are capped at 20MB and processed in memory; fine for
  typical monthly payroll sheets.
- The **PDF layout** is built to closely match your sample (colors, section
  order, attendance tiles, in-words net salary) but isn't a pixel-identical
  clone — let me know if specific spacing/branding needs tightening once
  you see it against real data.

## 6. Quick troubleshooting

| Symptom | Likely cause |
|---|---|
| Server starts but every page shows a login/API error | Oracle connection failed — check `.env` values, confirm the DB is reachable from this machine on port 1521 |
| `ORA-00001` on Add Employee | Employee Code already exists |
| `ORA-02292` on Delete Employee | Employee still has payroll records — delete those first |
| Excel upload says "Could not find an Employee Code column" | Add a header literally named "Employee Code" (or one of the accepted aliases) to row 1 of your sheet |
| Payslip PDF downloads but looks empty/wrong | Check that the payroll row has non-null numeric values — blank Excel cells are treated as 0 |
